# Power Plant ANN Model

This repository contains an Artificial Neural Network (ANN) built with PyTorch to predict **power plant energy output (PE)** based on environmental and operational parameters.

---

## Dataset Features
- **AT (Ambient Temperature)** – °C  
- **V (Exhaust Vacuum)** – cm Hg  
- **AP (Ambient Pressure)** – millibar  
- **RH (Relative Humidity)** – %  
- **PE (Power Output)** – MW (target variable)

---

##  Project Structure
- `model` → Defines the ANN architecture  
- `train` → Training loop
- `test` → evaluation    
- `README.md` → Documentation  
- `plots` → Training vs validation loss curves
